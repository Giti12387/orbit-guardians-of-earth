# ORBIT: Guardians of Earth

A cinematic space exploration and Earth observation experience inspired by AAA space visuals and futuristic NASA-style mission control.

## Highlights
- Polished opening/main menu with animated 3D Earth hero and working navigation.
- First playable mission: **Coastal Watch** (Earth Observation training).
  - Cinematic briefing
  - Interactive observation-layer gameplay
  - Premium mission results report
- Mission progress saved locally in the browser.

## Scientific note
The first mission uses **simulated training overlays** inspired by Earth observation concepts. It does not claim to display live NASA imagery.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
